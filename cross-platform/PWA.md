# Мои финансы на iPhone без подписи Apple

PWA добавляется на экран iPhone через Safari. Mac, Apple Developer и еженедельная переподпись не нужны. Актуальный ZIP для статического HTTPS-хостинга доступен в [Releases](https://github.com/Bel9shik/finance-computer/releases/latest). Целевая версия — iOS 17 и новее.

## Готовый архив

Архив `FinanceComputer-<версия>-PWA.zip` содержит готовые файлы приложения в корне ZIP. Контрольные суммы находятся в `SHA256SUMS.txt` того же релиза. В архиве нет выписок, финансовой базы, ключей подписи, тестовых данных или серверной части.

## Размещение

1. Распакуй архив. Загрузи **его содержимое** на статический хостинг с HTTPS. Подходит корень сайта или постоянная подпапка, например `https://example.com/finances/`.
2. Сохрани структуру файлов, включая `assets`, `sw.js`, `manifest.webmanifest` и иконки. Сервер должен отдавать JavaScript с MIME-типом `text/javascript` или `application/javascript`, а не HTML. Если используется подпапка, её адрес должен заканчиваться `/`; настрой перенаправление на этот адрес.
3. Для `sw.js`, `index.html` и `manifest.webmanifest` используй `Cache-Control: no-cache`. Файлы в `assets` имеют имена с хешами и могут кэшироваться надолго. Не меняй содержимое JS/HTML при выдаче и не подменяй отсутствующие JS-файлы страницей входа или `index.html`.
4. Открой HTTPS-адрес и дождись надписи **«Готово к работе без интернета»**. Она появляется после установки офлайн-кэша. Если подготовка не завершилась, проверь доступность всех файлов, HTTPS и настройки сервера.

Для размещения не требуются Node.js, Rust или база данных на сервере. Просто открыть `index.html` из ZIP или из приложения «Файлы» недостаточно: установка офлайн-режима требует HTTPS-адреса.

## Установка на iPhone

1. Открой адрес приложения именно в **Safari**.
2. Нажми **Поделиться → На экран Домой → Добавить**. Если есть переключатель **Открывать как веб-приложение**, включи его.
3. Открой новую иконку с подключённым интернетом. Дождись **«Готово к работе без интернета»** уже в установленном приложении. Только после этого начинай перенос данных.
4. Добавь PDF/XLSX через **Добавить выписки** либо перенеси базу JSON через **Загрузить копию**.
5. Для проверки закрой приложение, включи авиарежим и открой иконку снова. Проверь отображение данных и импорт заранее скачанной выписки из **На моём iPhone**. Файлы, оставшиеся только в iCloud, могут потребовать интернета для загрузки системой.

У приложения нет срока действия подписи Apple. Данные сайта могут быть удалены при очистке хранилища или удалении веб-приложения; система также может освобождать место. Приложение запрашивает постоянное хранение, но решение принимает Safari. Поэтому сохраняй внешние JSON-копии важных данных. Это резервное копирование, а не переустановка.

Добавление сайта на экран описано у [Apple](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios), особенности хранения — у [WebKit](https://webkit.org/blog/14403/updates-to-storage-policy/).

## Файлы, копии и обновления

- Разбор PDF/XLSX выполняется на устройстве. Приложение не отправляет выписки или финансовую базу на хостинг.
- База сохраняется в IndexedDB. Не используй приватный режим Safari для постоянного учёта. После установки начинай пользоваться иконкой приложения: не рассчитывай на перенос состояния из предварительно открытой вкладки Safari.
- **Сохранить копию** открывает системное меню передачи файла, если оно поддерживается. Выбери **Сохранить в Файлы**, проверь имя и сохранение JSON. В других браузерах файл скачивается. Для переноса только правил и имён доступны экспорт/импорт настроек.
- Перед очисткой, заменой базы и импортом настроек сохраняется одна предыдущая копия. Её можно восстановить через **Импорт → Восстановить автоматическую копию**. Она находится в том же хранилище и не защищает от очистки данных сайта; следующая такая операция заменяет её.
- Запись базы и автоматической копии выполняется одной транзакцией. При ошибке записи прежние данные остаются. Устаревшее окно не может перезаписать более свежие изменения другого окна: приложение предложит открыться заново.
- JSON-копии содержат операции и реквизиты в открытом виде. Для локального хранения выбирай **На моём iPhone**, а не облачную папку.
- При обновлении загружай новую сборку по **тому же HTTPS-адресу**. Затем открой приложение с интернетом и закрой все его окна после загрузки обновления. Новая версия активируется после закрытия старых окон; база не удаляется. Не удаляй иконку для обычного обновления.

## Что проверено

На Mac 23 октября 2026:

- 40 автоматических тестов: финансовое ядро, PDF/XLSX, категории и пресеты, перенос настроек, ошибки файловых операций, политика офлайн-кэша.
- Проверка собранного пакета: все ресурсы включены в кэш, включая оба Worker, пути работают из подпапки, иконки имеют правильные размеры, тесты и пользовательские данные не включены.
- 44 проверки PWA в изолированном нативном WebKit на размерах 390×844 и 844×390, включая тёмную тему: настоящее IndexedDB, откат при ошибке записи, конфликт окон, восстановление повреждённой базы, импорт PDF/XLSX, экспорт JSON, автоматическая копия, перенос настроек и фактическая перезагрузка страницы с сохранёнными данными. Выбор файлов и системное меню передачи имитируются; тестовое хранилище изолировано от реальной базы.
- Проверка прежнего нативного интерфейса на ширине 390 и 1250, сборки PWA и нативного интерфейса.

**Не проверены на устройстве:** установка на экран iPhone, системные диалоги Safari и настоящий Service Worker в Safari. По просьбе пользователя браузер не запускался. Логика офлайн-кэша проверена автоматическими тестами с моделированием событий; это не заменяет финальную проверку в авиарежиме после размещения. Перезапуск процесса установленного приложения и долговременное хранение iOS также требуют проверки на iPhone.

## Повторная сборка и тесты

Для сборки достаточно Node.js 24 и npm. Из каталога `cross-platform`:

```sh
npm ci
python3 ../Tests/make_fixtures.py
npm test
npm run build:pwa
```

Готовый сайт появится в `dist-pwa`. `npm run build` по-прежнему готовит отдельный `dist` для Tauri. Изменения интерфейса и финансовых правил общие, адаптеры хранения и файлов различаются.

Дополнительные проверки на Mac с Command Line Tools, без браузера:

```sh
bash scripts/test-pwa.sh 390 844
bash scripts/test-pwa.sh 844 390 dark
npm run build
bash scripts/test-webview.sh 390 844
bash scripts/test-webview.sh 1250 880
```
