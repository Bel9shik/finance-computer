# Мои финансы

Офлайн-приложение для учёта финансов из нескольких банков: операции, категории, пресеты, люди и графики. Общая версия для macOS, Windows, Linux и Android написана на React/TypeScript и Rust/Tauri.

[Скачать актуальный релиз](https://github.com/Bel9shik/finance-computer/releases/latest) · [Все релизы](https://github.com/Bel9shik/finance-computer/releases) · [Документация](cross-platform/README.md)

## Возможности

- Импорт нескольких текстовых PDF Т-Банка, Яндекс Банка (Пэя), Сбербанка и XLSX Альфа-Банка. Проверка банковских итогов; повреждённая выписка отклоняется целиком.
- Категории и редактируемые правила MCC, группы продавцов, сохранённые пресеты и индивидуальные исправления операций.
- Раздельные расходы, поступления, возвраты, накопления и переводы между своими счетами.
- Свои номера телефонов, имена людей и история переводов человеку и от него.
- Круговые диаграммы и графики по месяцам/дням, фильтры и открытие операций по нажатию на график.
- Импорт и экспорт полной резервной копии либо только настроек, пресетов и справочника людей.

## Установка

Скачай нужный файл из [Releases](https://github.com/Bel9shik/finance-computer/releases/latest).

| Платформа | Пакет |
| --- | --- |
| macOS 13+, Apple Silicon и Intel | Universal DMG; перенеси приложение в Applications |
| Windows 10/11, x64 | EXE-установщик с офлайн WebView2 |
| Linux, x64 | DEB или AppImage; для AppImage потребуется право на выполнение |
| Android 7+, arm64 | APK с прежней подписью приложения; нужен актуальный системный WebView |
| PWA, включая iPhone | ZIP для размещения на HTTPS-хостинге, [инструкция](cross-platform/PWA.md) |

Mac-сборка имеет локальную подпись и не нотариализована Apple. Windows-установщик не имеет подписи издателя. Проверки на Windows Server в CI не заменяют проверку конкретных Windows 10/11. Подписанного нативного IPA для iPhone нет; [подготовка iOS-сборки](cross-platform/IOS.md) описана отдельно.

## Локальные данные

Нативное приложение не обращается к банковским API и не отправляет операции наружу. Парсеры и интерфейс входят в сборку. Нет аналитики, внешних шрифтов и автоматических обновлений. На Android отсутствует разрешение INTERNET; на настольных системах внешние запросы блокируются в приложении.

База и пользовательские настройки хранятся на устройстве. Экспорт JSON не зашифрован. Выписки, базы, резервные копии и ключи подписи не входят в этот репозиторий. PWA нужно сначала открыть с доступом к своему хостингу; затем её ресурсы доступны из офлайн-кэша.

## Сборка из исходников

Нужны Node.js 24, Rust stable и системные зависимости Tauri для выбранной платформы. Подробности и команды мобильных сборок: [cross-platform/README.md](cross-platform/README.md).

```sh
git clone https://github.com/Bel9shik/finance-computer.git
cd finance-computer/cross-platform
npm ci
python3 ../Tests/make_fixtures.py
npm test
npm run desktop
```

Тестовые выписки генерируются из вымышленных данных. Повседневная работа приложения полностью локальная; первичная сборка скачивает зависимости разработчика.

## Структура и релизы

- `cross-platform/` — актуальные интерфейс, финансовое ядро, парсеры, нативные адаптеры и тесты.
- `Sources/`, `Tests/`, корневые shell-скрипты — сохранённая прежняя Swift-версия для Mac и её тесты.
- `.github/workflows/release.yml` — сборка и проверка актуальных пакетов по тегу `vX.Y.Z`, затем создание черновика релиза с SHA-256.
- Ручные workflows — дополнительные проверки настольных систем и компиляции неподписанного iOS-приложения.

Android APK можно подписывать локально прежним ключом; ключ в репозиторий не добавляется. Без настроенных секретов CI сохраняет неподписанный APK отдельно и не включает его в готовые установщики. Перед публикацией черновика добавляется проверенный подписанный APK и обновляются контрольные суммы.
